Cupom Search

Cole o link do produto e veja quais cupons têm chance real de funcionar.

Quer certeza em vez de estimativa?

A extensão testa cada código no seu próprio carrinho, mede o desconto real e devolve o resultado para todo mundo. Instruções em extension/README.md.

Lojas suportadas

    A confiança é uma estimativa a partir de regras do cupom, frescor da fonte e do que a comunidade relatou — o cupom só é confirmado de verdade no checkout da loja.
